# Правители России

Русскоязычный исторический атлас: линия правителей от Рюрика до наших дней, синхронная линия крупных событий и линия жизни известных художников.

## Разработка

```sh
npm ci --include=dev
npm run dev
npm run typecheck
npm run build
npm run preview
npx playwright install --with-deps chromium
npm test
```

## Возможности

- 33 исторических события между правителями и художниками: войны, революции, реформы и открытия.
- По две репродукции для каждого художника (72 изображения), названия, даты и источники. Изображения загружаются локально и только при открытии справки.
- Связи событий с произведениями различают отклик современника, позднейшее изображение и общий исторический контекст.
- 36 художников: русская живопись и мастера других культур, жившие или работавшие в России.
- Годы жизни художников на общей шкале с правлениями; перекрывающиеся жизни в отдельных строках.
- Ссылки между художниками и правителями-современниками в обе стороны.

- Пропорциональная временная шкала с восемью уровнями масштаба.
- Переход к эпохе, выбор правителя и обзор всей истории.
- Приход к власти и завершение правления для каждого правителя; штрихованные пояснения вместо пустых дат.
- Краткие справки по наведению, фокусу или нажатию; на телефоне — нижняя карточка.
- Горизонтальная прокрутка касанием и трекпадом, кнопки навигации и клавиатура.
- Без клиентского фреймворка и внешних шрифтов. Справки доступны и без JavaScript.

## Структура

- `src/data/timeline.ts` — правители, даты, эпохи и пояснения периодов.
- `src/data/events.ts` — события, последствия и проверенные связи с искусством.
- `src/data/artworks.json` — репродукции, датировки и атрибуция; `public/artworks/` — оптимизированные изображения.
- `src/data/painters.ts` — биографии художников, годы жизни и раскладка перекрывающихся интервалов.
- `src/data/succession.ts` — приход к власти и завершение правления.
- `SOURCES.md` — источники и ограничения исторической модели.
- `src/pages/index.astro` — разметка страницы.
- `src/styles/timeline.css` — адаптивный дизайн.
- `src/scripts/timeline.ts` — масштаб, навигация и карточки.
- `tests/timeline.spec.ts` — проверки взаимодействий на экранах 1440, 390 и 320 пикселей.

Ранняя история представлена выборочно. Перерывы, соправление и особенности советского руководства поясняются в справках и примечании. Доли года используются для приблизительного размещения коротких правлений; отображаемые даты заданы отдельно. Современные сведения проверены в сентябре 2026 года.
