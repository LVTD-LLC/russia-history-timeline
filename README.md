# Russia History Timeline

История России на интерактивной шкале времени. Русскоязычный исторический атлас: единая линия времени с правителями, крупными событиями и известными художниками.

## Разработка

```sh
npm ci --include=dev
npm run dev
npm run typecheck
npm run build
npm run preview
npx playwright install --with-deps chromium
npm test
```

## Возможности

- 33 исторических события на общей шкале: войны, революции, реформы и открытия.
- По две репродукции для каждого художника (72 изображения), названия, даты и источники. Изображения загружаются локально и только при открытии справки.
- Связи событий с произведениями различают отклик современника, позднейшее изображение и общий исторический контекст.
- 36 художников: русская живопись и мастера других культур, жившие или работавшие в России.
- Годы жизни художников на общей шкале с правлениями; перекрывающиеся жизни в отдельных строках.
- Ссылки между художниками и правителями-современниками в обе стороны.

- Пропорциональная временная шкала с восемью уровнями масштаба.
- Переход к эпохе, выбор правителя и обзор всей истории.
- Приход к власти и завершение правления для каждого правителя; штрихованные пояснения вместо пустых дат.
- Единые карточки с цветами категорий и легендой; пересекающиеся записи расположены в отдельных строках общей области прокрутки.
- Справки только по нажатию: выезжающая справа панель на половину экрана компьютера и весь экран телефона. Escape, кнопка закрытия и Back возвращают к линии.
- Отдельный адрес каждой справки (например, `/repin/`), работающий при прямом переходе и перезагрузке.
- Горизонтальная прокрутка касанием и трекпадом, кнопки навигации и клавиатура.
- Без клиентского фреймворка и внешних шрифтов. Справки доступны и без JavaScript.

## Структура

- `src/data/timeline.ts` — правители, даты, эпохи и пояснения периодов.
- `src/data/events.ts` — события, последствия и проверенные связи с искусством.
- `src/data/artworks.json` — репродукции, датировки и атрибуция; `public/artworks/` — оптимизированные изображения.
- `src/data/painters.ts` — биографии художников, годы жизни и раскладка перекрывающихся интервалов.
- `src/data/succession.ts` — приход к власти и завершение правления.
- `SOURCES.md` — источники и ограничения исторической модели.
- `src/components/Atlas.astro` — общая разметка атласа.
- `src/pages/index.astro` и `src/pages/[slug].astro` — главная и статические адреса справок.
- `src/data/entries.ts` — общая хронология и уникальные идентификаторы маршрутов.
- `src/styles/timeline.css` — адаптивный дизайн.
- `src/scripts/timeline.ts` — масштаб, навигация и карточки.
- `tests/timeline.spec.ts` — проверки взаимодействий на экранах 1440, 390 и 320 пикселей.

Ранняя история представлена выборочно. Перерывы, соправление и особенности советского руководства поясняются в справках и примечании. Доли года используются для приблизительного размещения коротких правлений; отображаемые даты заданы отдельно. Современные сведения проверены в сентябре 2026 года.

Astro 7 · статический HTML/CSS/TypeScript · Docker и CapRover через `captain-definition`.

## Автоматический деплой

Каждое обновление `main` запускает CI (проверка типов, сборка и браузерные тесты), затем `.github/workflows/deploy.yml` отправляет проверенный коммит в приложение CapRover `russia-history-timeline`. Деплои выполняются последовательно; устаревшие коммиты пропускаются. Pull request не запускает деплой.

В GitHub Actions настроен секрет `CAPROVER_APP_TOKEN` — токен только этого приложения, без пароля администратора CapRover. Адреса сервера и сайта указаны в workflow. Архив содержит только файлы из Git и маркер `/deploy-revision.txt`; успешный запуск подтверждает, что сайт действительно отдаёт SHA проверенного коммита.

Для повторного деплоя: Actions → CI → Run workflow → `main`. Ошибка загрузки или отсутствие ожидаемого коммита на сайте завершает деплой с ошибкой; предыдущая версия не считается успешным обновлением. Состояние сборки и подробные логи доступны в CapRover.
